# Noa — Small Incomplete Landing Page

A small, intentionally incomplete Persian (RTL) landing page built with **HTML5, CSS3, and Bootstrap 5**.

> Created in approximately 20 minutes as part of a coding test at my institute.

## Overview

Noa is a simple landing page concept designed to practice Bootstrap 5 and core frontend development skills.

The project demonstrates a basic landing page structure, responsive layouts, Bootstrap components, custom CSS styling, and a mobile navigation menu.

It is an intentionally unfinished practice project rather than a complete production-ready website.

## Features

### 1. Navigation

- Brand logo and website navigation.
- Bootstrap responsive navbar.
- Navigation links for Home, Services, About, and Contact.
- Call-to-action button.
- Mobile navigation using Bootstrap Offcanvas.
- Separate navigation layout for smaller screens.

### 2. Hero Section

- Modern web design badge.
- Main heading with highlighted text.
- Short introductory description.
- Two call-to-action buttons:
  - Start Project
  - Learn More
- Hero illustration.

### 3. Features Section

A dedicated section introducing three main concepts:

- **Responsive Layout:** Demonstrates Bootstrap's grid system for different screen sizes.
- **Bootstrap Components:** Highlights the use of reusable UI components and styling utilities.
- **Clean Structure:** Presents the idea of organized and readable code.

### 4. Styling and UI

- Persian RTL layout.
- Custom Yekan font.
- Blue primary color theme.
- Rounded navigation and feature cards.
- Custom button hover effects and transitions.
- Card shadows and borders.
- Font Awesome icons.
- Custom CSS variables and Bootstrap theme overrides.

### 5. Responsive Design

- Bootstrap responsive grid system.
- Desktop navigation and mobile Offcanvas menu.
- Responsive hero layout.
- Responsive feature cards.
- Custom small-screen heading adjustment.

## Technologies Used

- **HTML5** — Page structure and semantic elements.
- **CSS3** — Custom styling, layouts, transitions, and responsive adjustments.
- **Bootstrap 5** — Responsive grid, navbar, Offcanvas, buttons, and utility classes.
- **Font Awesome** — Interface icons.
- **Yekan Font** — Persian typography.
